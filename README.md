## 🎯 À propos

Ce dépôt contient le projet **Gestion de Projet — Scrum**.

L'application a pour objectif de faciliter la collaboration des équipes, le suivi des projets et la communication en temps réel.

---

## 🛠️ Stack technique

| Couche | Technologies |
|---|---|
| **Frontend** | React, TypeScript |
| **API Gateway** | NestJS |
| **Microservices** | NestJS |
| **Base de données** | PostgreSQL |
| **ORM** | TypeORM |
| **Cache** | Redis |
| **Message Broker** | RabbitMQ |
| **Chat en temps réel** | Socket.IO |
| **Audio / Vidéo** | WebRTC, LiveKit |
| **Stockage de fichiers** | MinIO |
| **Emails** | Nodemailer, SMTP |
| **Reverse Proxy** | Nginx |
| **Conteneurisation** | Docker, Docker Compose |
| **CI/CD** | GitHub Actions |
